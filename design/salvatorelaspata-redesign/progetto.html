CAP Plugin Adobe Forms

Plugin CAP riutilizzabile che integra Adobe Forms per generare PDF dai servizi. Configuri una destination, chiami un servizio, ottieni il PDF.

Codice su GitHub (si apre in una nuova scheda) Pacchetto npm (si apre in una nuova scheda)

Il problema

In tre progetti diversi avevo copiato la stessa integrazione con Adobe Forms by Adobe sulla SAP BTP: token OAuth2, conversione dei dati in XML, chiamata al servizio di rendering. Ogni copia aveva i suoi bug.

Mi serviva un modo dichiarativo per usare Adobe Forms da un servizio CAP, come si fa con qualsiasi altro servizio remoto.

Come funziona

  1. Il plugin si registra come servizio CAP di tipo adobe-forms.
  2. Le credenziali arrivano da una destination BTP, quindi niente segreti nel codice.
  3. I dati CDS vengono convertiti in XML secondo lo schema del template.
  4. Il PDF torna come stream, pronto da allegare o da restituire al client.

Installazione

terminale
# nel progetto CAP
npm add cap-plugin-adobe-forms
package.json
{
  "cds": {
    "requires": {
      "adobe-forms": {
        "kind": "adobe-forms",
        "credentials": { "destination": "ADS" }
      }
    }
  }
}

Uso in un handler

srv/invoice-service.js
const ads = await cds.connect.to('adobe-forms')
const pdf = await ads.render({
  template: 'ZINVOICE',
  data: invoice   // oggetto CDS → XML in automatico
})

Nota. Il plugin non sostituisce la licenza Adobe Forms: serve un tenant con il servizio attivo sulla BTP.

Cosa ho imparato

Il meccanismo dei plugin CAP è più potente di quanto sembri: con cds-plugin.js puoi aggiungere tipi di servizio interi senza toccare il progetto ospite. Il resto del lavoro è stato scrivere test sugli schemi XML, la parte meno glamour e più utile.
